# 🌱 Mundo Mais Verde

## 📌 Sobre o projeto

O **Mundo Mais Verde** é um projeto de site desenvolvido para uma ONG fictícia voltada à preservação ambiental e à conscientização sobre a importância de práticas sustentáveis.

O projeto apresenta informações sobre a organização, seus projetos e disponibiliza um formulário de cadastro para os usuários.

## 🛠️ Tecnologias utilizadas

* **HTML5** – estrutura e organização semântica das páginas.
* **CSS3** – estilização, layout, responsividade e identidade visual.
* **JavaScript** – interações, validações do formulário, navegação e manipulação do DOM.
* **Git/GitHub** – controle de versão e organização do desenvolvimento.

## ▶️ Como executar localmente

1. Clone o repositório para o computador.
2. Acesse a pasta do projeto.
3. Abra o arquivo principal `.html` em um navegador.
4. Navegue pelas páginas e funcionalidades disponíveis.

O projeto não possui dependências externas ou processo de build obrigatório, portanto não é necessário instalar pacotes adicionais para executá-lo.

## 🌿 Versionamento

O desenvolvimento foi organizado utilizando uma estratégia baseada no **GitFlow**, com as branches:

* `main` – versão estável do projeto.
* `develop` – branch destinada ao desenvolvimento contínuo.
* `feature/` – branches utilizadas para desenvolver funcionalidades individualmente.

As alterações foram integradas por meio de **Pull Requests**, utilizados para documentar e revisar as funcionalidades antes da integração com a `develop`.

Entre os principais PRs estão:

* Projetos
* Cadastro
* Estilo
* Validação e menu responsivo

As mensagens de commit seguem, quando aplicável, o padrão **Conventional Commits**, utilizando tipos como `feat` para novas funcionalidades e `fix` para correções.

## 📋 Funcionalidades

* Página inicial da ONG.
* Página de projetos.
* Formulário de cadastro.
* Navegação entre páginas.
* Menu responsivo.
* Validação do formulário.
* Layout responsivo para diferentes tamanhos de tela.
